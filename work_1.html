002 : North-West University — BSc IT

Completed my BSc in Information Technology at NWU Potchefstroom, where the degree's focus on programming fundamentals and methodology gave me practical experience across a wide range of languages and paradigms. Java formed the backbone of object-oriented programming; C#, JavaScript, HTML and SQL were used for GUIs, webpages and database systems; Python for a chat-app architecture and data analysis projects; and MATLAB and R for mathematics, physics and statistics modules. I took a leading role in team projects, applying Agile methodology across the full software development lifecycle.

Java C# JavaScript Python SQL HTML / CSS R MATLAB Agile Git

Final Year Modules

Databases

Design, implementation and querying of relational and non-relational database systems using SQL and advanced database concepts.

Advanced Databases

Extended topics covering database optimisation, transactions, indexing strategies, distributed databases and big-data storage patterns.

Decision Support Systems I

Introduction to decision-support architectures, data warehousing, OLAP and business intelligence tools that inform strategic decisions.

Decision Support Systems II

Advanced DSS topics including model-driven and data-driven decision systems, dashboards and predictive analytics pipelines.

Artificial Intelligence

Foundations of AI including search algorithms, knowledge representation, machine learning concepts and practical applications.

Computer Networks

TCP/IP protocol suite, network architectures, routing, switching, network services administration and troubleshooting.

Operating Systems

Process management, memory management, file systems, concurrency and the principles underlying modern OS design.

IT Developments

Current and emerging trends in the IT industry, covering topics such as cloud computing, IoT, cyber security and the future of software.
